# Code of Conduct

## Our Pledge

Serendipity Maps is built on the belief that connection should be organic, respectful, and consent-driven. This project — and its community — must reflect those values.

## Standards

Behavior that contributes to a positive environment includes:

- **Respect** for differing viewpoints, experiences, and backgrounds
- **Empathy** toward newcomers and experienced contributors alike
- **Constructive** feedback focused on ideas, not individuals
- **Inclusivity** in language, design, and technical decisions
- **Privacy awareness** — treating user data sensitivity as a core value

Unacceptable behavior includes:

- Harassment of any kind
- Trolling, insulting, or derogatory comments
- Publishing others' private information
- Any conduct that would be inappropriate in a professional setting

## Scope

This Code of Conduct applies to all project spaces: repository, issues, PRs, discussions, and any linked community channels.

## Enforcement

Instances of unacceptable behavior may be reported by contacting the maintainer. All complaints will be reviewed and addressed fairly.
